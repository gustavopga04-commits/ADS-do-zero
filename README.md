# ADS do zero

Meus estudos de programação do curso de Análise e Desenvolvimento de Sistemas (Estácio).
Repositório com os exercícios e desafios em **C** e **Python**.

## 📁 Estrutura

```
.
├── c/          -> exercícios e desafios em Linguagem C
│   └── antigos/  -> versões antigas do Super Trunfo (histórico de estudo)
└── python/     -> exercícios em Python
```

## 💻 Linguagem C (`c/`)

| Arquivo | Descrição |
|---|---|
| `super_trunfo.c` | **Desafio Super Trunfo** — cadastro de cartas, cálculos (densidade, PIB per capita) e comparação entre cartas |
| `modularidade_media.c` | Cálculo de média usando funções, vetor e ponteiro |
| `operadores_matematicos.c` | Operadores matemáticos e divisão com casas decimais |
| `Matricula_Alunos.c` | Entrada e saída de dados (matrícula de alunos) |
| `soma.c` | Soma de dois números |
| `olamundo.c` | Primeiro programa |

## 🐍 Python (`python/`)

| Arquivo | Descrição |
|---|---|
| `missao01_cruzeiro.py` | Missão 01 — ficha do Cruzeiro |
| `missao02_hotdog.py` / `missao02_hotdog_final.py` | Missão 02 — calculadora de hot-dog |
| `missao03_jogo_hoje.py` | Missão 03 — jogo de hoje |
| `DesafioDiario01.py` | Desafio diário 01 |
| `exercicio_imc.py` | Cálculo de IMC |
| `exercicio_input.py` | Exercício de entrada de dados |

## ⚙️ Como compilar e executar os programas em C

```bash
gcc c/super_trunfo.c -o super_trunfo.exe
./super_trunfo.exe
```

No VS Code, com o arquivo `.c` aberto: **`Ctrl` + `Shift` + `B`** (compila e roda) ou **`F5`** (compila e roda com depurador).
